# Contributing

Sacred Near Me is in Phase 0 — Governance and repository foundation.

Outside contributions are not currently accepted. Unsolicited pull requests may be closed without review.

Issues may be used for approved project work and defect tracking under the repository's governance and work-management rules. Public visibility is provided for transparency and project governance; it is not an invitation to contribute and does not grant an open-source license.

The contribution policy may be reconsidered in a later project phase through an explicit Product Owner decision.
